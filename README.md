# Myntra Fashion Sales Dashboard - Power BI

## 📊 Project Overview
End-to-end sales analysis of 5000 Myntra fashion products with Time-Series Forecasting.

## 📁 Dashboard Pages (7 Pages)
1. Sales Overview - KPIs, Revenue Trends
2. Category Analysis - Best Selling Categories
3. Discount Analysis - Profit vs Discount Impact
4. Demand Forecast - Category-wise Quantity Forecast (Dresses ↓, Leggings ↑, Jeans →)
5. Sales Forecast - Monthly Sales Forecast with Seasonality (Peak: Dec Festive)

## 🔧 Tools Used
- Power BI Desktop (DAX, Forecasting, Small Multiples)
- Excel Data Cleaning

## 💡 Key Insights
- Monthly sales peak in May & Dec (festive), lowest in Apr
- Dresses demand declining, Leggings increasing in last quarter
- Next 3 months sales forecast: 0.8M-1.0M stable recovery
- Recommendation: Increase T-Shirts & Kurtas inventory before Dec
